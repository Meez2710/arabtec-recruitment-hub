Component Gallery

This page is a checked-in, static reference for every UI component the product actually uses — it is not part of the app's routes, is not linked from the sidebar, and ships no JavaScript logic of its own. It exists because the frontend has no bundler (app.jsx is compiled in-browser by the vendored Babel) and Storybook would require a build pipeline this app deliberately does not have.

Every element below is copied verbatim out of app.jsx (or, where a component lives in cv-intake.jsx, transcribed from what it renders). When a component's markup changes in the product, this page must be updated in the same change — that discipline is enforced by backend/ui_gallery_test.mjs, which asserts every class name below still exists and that this page loads the same five stylesheets, in the same order, at the same cache-bust token as index.html.

Loaded stylesheets: styles.css, arabtec-approved-ui.css, arabtec-design-system.css, claude-system.css, arabtec-responsive.css — all at ?v=20260913c.
